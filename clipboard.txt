好！这个程序叫**云电脑控制系统**，由三部分组成：

---

**第一部分：云电脑上的 main.py**

在云电脑后台运行，负责：
- 每秒截图上传到 Google Drive
- 监听 GitHub 上的命令文件
- 收到命令后执行：点击鼠标、输入文字、按键、粘贴到Doc等
- 监听云电脑剪贴板变化，自动上传到 GitHub

---

**第二部分：本机控制面板（Apps Script Web App）**

在本机浏览器打开，负责：
- 显示云电脑实时截图（每秒刷新）
- 点击屏幕控制鼠标
- 工具栏按钮：全选、复制、发送文字、滚动、读取剪贴板、写入Doc
- 把命令写入 GitHub，云电脑收到后执行

---

**第三部分：云电脑的剪贴板同步页面**

云电脑打开 `网址?mode=clip`，负责：
- 读取云电脑浏览器剪贴板
- 上传到 GitHub
- 本机点"读取剪贴板"就能看到内容

---

**整体流程：**
```
本机 → GitHub → 云电脑（命令）
云电脑 → Google Drive → 本机（截图）
云电脑 → GitHub → 本机（剪贴板）
```
