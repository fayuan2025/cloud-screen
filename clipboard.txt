URL 输入了两次！因为地址栏已经有内容，`type` 直接追加上去了。

修复——先清空地址栏再输入：

```bash
python3 << 'PYEOF'
with open('/home/user/cloud-screen/main.py', 'r') as f:
    content = f.read()

old = """    subprocess.run(['xdotool', 'search', '--class', 'chrome', 'key', '--clearmodifiers', 'ctrl+t'], env=ENV)
    time.sleep(1)
    doc_url = 'https://docs.google.com/document/d/1cV6eqGBgVLj-xK5Z1opY9mr4Sm77zOfjtITPjSlXq1A/edit'
    subprocess.run(['xdotool', 'search', '--class', 'chrome', 'type', '--clearmodifiers', doc_url], env=ENV)"""

new = """    subprocess.run(['xdotool', 'search', '--class', 'chrome', 'key', '--clearmodifiers', 'ctrl+t'], env=ENV)
    time.sleep(1)
    doc_url = 'https://docs.google.com/document/d/1cV6eqGBgVLj-xK5Z1opY9mr4Sm77zOfjtITPjSlXq1A/edit'
    subprocess.run(['xdotool', 'search', '--class', 'chrome', 'key', '--clearmodifiers', 'ctrl+l'], env=ENV)
    time.sleep(0.3)
    subprocess.run(['xdotool', 'search', '--class', 'chrome', 'type', '--clearmodifiers', doc_url], env=ENV)"""

content = content.replace(old, new)
with open('/home/user/cloud-screen/main.py', 'w') as f:
    f.write(content)
print('完成 ✅')
PYEOF
```

重启：
```bash
pkill -f main.py && sleep 1 && cd ~/cloud-screen && source venv/bin/activate && python3 main.py &
```
